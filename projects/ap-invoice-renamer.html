02 PROJECT CASE STUDY

AP Invoice Renamer.

Turning a repetitive invoice-handling task into a more controlled workflow, with structured naming, document checks, and clearly defined human-review steps.

FOCUS
Accounts payable · Document processing · Internal controls
TOOLS / METHODS
Python · PDF parsing · OCR fallback · CSV rules and logs
APPLICATION
Manufacturing AP operations

The challenge

AP teams receive invoices in inconsistent formats and filenames. Renaming, sorting, and routing each file manually takes time, creates inconsistent records, and complicates invoice retrieval. Automation must be cautious: a misidentified vendor or invoice number can be worse than a document left for review.

What I built

I designed a Python-based document workflow to inspect AP invoices, identify vendor and reference information, apply standardized filenames, and organize eligible files by vendor. The underlying system uses vendor-specific matching rules alongside general parsing logic, with manual checkpoints for documents that cannot be classified confidently.

Key engineering decisions

  1. Extract from the actual document. Read PDF text rather than trusting filenames; use OCR as a fallback for image-based documents, with additional review for uncertain results.
  2. Standardize naming and routing. Build a consistent vendor / invoice reference / PO structure that makes saved documents easier to locate.
  3. Handle document complexity. Account for multi-invoice PDFs, credits, statements, and supporting documents with specialized logic.
  4. Protect against duplicate filing. Check existing records, distinguish exact copies from changed invoice versions, and flag possible duplicates.
  5. Make exceptions visible. Send ambiguous or unsupported documents to a review process rather than silently guessing.
  6. Keep the process traceable. Support preview runs, operator-readable status groups, and structured activity logs.

Business value

This workflow reduces repetitive invoice preparation and promotes consistent AP filing conventions, while reserving judgment-based exceptions for the accounting team. It is part of the wider group of AP, AR, and BOM process improvements that I estimate saved 5–10 total staff-hours per workweek; that estimate is combined, self-reported, and not a standalone savings figure for this tool.
